# Bank Transaction Analyzer

A beginner-friendly data engineering and machine-learning project that explores transaction data, detects unusual activity, and presents useful insights.

## Goals

- Load transaction data from CSV into a SQLite database
- Explore spending patterns with SQL
- Flag suspicious transactions using transparent rule-based checks
- Add machine-learning anomaly detection with Isolation Forest
- Compare the rule-based and ML-based results

## Planned stack

Python, SQLite, pandas, matplotlib, scikit-learn

## Project status

The project is being built step by step. Each commit represents a clear, explainable milestone.
